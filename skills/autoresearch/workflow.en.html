Understand the document roles first

How the Skill turns research rules into real project documents

The Skill routes the whole workflow, Prompts guide the current step, Rules constrain decisions, and Templates shape outputs. AI ultimately creates and maintains the real documents inside the research project.

Director · Router

SKILL.md

Identifies the current research phase and selects the Prompts, rules, and templates that must be read next.

Real project state and evidence

Generated Documents

DATASET_PROFILE.md, RESEARCH_BRIEF.md, BENCHMARK.md, experiment logs, and Stage Summaries.

Progressive loading: SKILL.md and the single ALWAYS contract form the persistent context. Each cycle activates exactly one PHASE; templates, logs, and detailed field rules remain ON_DEMAND.

CONTEXT.md: records how this Skill is designed and adjudicated; it is not a research document generated during an experiment.

Workflow HTML: helps people and AI understand file relationships and the lifecycle. It visualizes and routes; it does not create research rules.

Stage Details

1 · Input & Alignment

This is the phase with the most human involvement and the only mandatory human approval. AI verifies before it asks.

Inputs

  • Dataset files and project code
  • User's complete requirement and performance goal
  • Research budget and authorized execution boundary

Sequence

  1. Inspect runnable code and safely bootstrap ReproFlow only when absent
  2. Generate and validate Codebase Profile
  3. Read the data and generate Dataset Profile
  4. Autofill inferable fields
  5. Ask 3–5 questions about PENDING fields
  6. Generate the Research Brief draft

Exit gate

The codebase is validated or mapped, every required Research Brief field is complete, and the user gives the final confirmation. No per-experiment approval follows.

2 · Research Planning

Turn the frozen objective into a non-drifting evaluation contract and a progressively disclosed research roadmap.

Must freeze

  • One Primary Metric and Performance Target
  • Zero or more Hard Constraints
  • Data split, evaluation script, and stopping protocol
  • At least one unit-explicit cap: wall_clock_hours / gpu_hours / monetary_cost + currency / formal_experiment_count
  • Anchor Baseline or Baseline Pending status

Outputs

3 · Literature & Candidates

Literature search is not a one-time opening step. Re-enter it during reproduction, repair, and later component innovation.

Actions

  • Select, download, and verify 3–4 nearest papers by default; quantity needs no further confirmation after Brief freeze
  • Recover the actual algorithmic mechanism
  • Choose full-method or component-level R/A reproduction
  • Run at most three evidence-backed Paper Repair hypotheses when needed
  • Prosecute N candidates for pseudo-innovation and structural risk

Outputs

Literature survey, one Paper Mechanism Card per paper, and R/A/N experiment candidates that pass the gates.

4 · Experiment Loop

Execution is fully unattended, but every Candidate remains falsifiable, comparable, and traceable.

Mandatory loop

Hypothesis → prediction and falsifier → change → smoke → full run → judgment → keep / rollback / repair

Runtime boundary

The LLM owns mechanisms, hypotheses, interpretation, and routing. Judgment-only Graph Operations stay in the handoff; persistent operations map to propose or start-run. Only start-run creates the Experiment ID, Attempt, and Card. inspect returns machine-owned current_phase + last_trigger + active_run as the sole recovery entry. Success uses accepted / revision / result; rejection uses error_code / violations / allowed_next_actions. Formal runs preregister resolved config, metrics JSON, manifest, trainer-log paths, and the Brief-derived cost unit; Runtime reads real artifacts before changing scientific state. The LLM never edits canonical JSON, Runtime State, or derived HTML directly.

Classification & gates

  • Five-dimensional Experiment Classification
  • Gold / Silver / Hold / Reject for N candidates
  • Research Base promotion: TWO_SEEDS / ONE_CONFIRM_SEED / SINGLE_RUN_JUSTIFIED
  • Branch Addition Gate
  • Simplification Campaign

Logging layers

  • Experiment Card: Runtime owns and hashes Runtime Record; the LLM may only append Research Notes
  • Research Experiment Log: concise research narrative
  • Run Event Log: JSONL machine event stream
  • Trainer output: referenced artifact only

5 · Stage Reflection

A Stage Summary is not a compressed log. It is first-principles analysis, adversarial review, and route selection over frozen evidence.

Triggers

  • Ten completed formal experiments
  • Research Base promotion
  • Formal Benchmark change
  • Research direction closed or switched
  • Paper Repair Cycle completed

Six fixed questions

  1. What do we actually know?
  2. Why did these results happen?
  3. Where might we be wrong?
  4. What transferable lessons remain?
  5. Which next directions are discriminating?
  6. Which route should research take now?

On-demand gate

Read the Interaction Review Gate only for a cross-branch combination; Stage Reflection does not duplicate its rules.

Routes

DEEPEN / BROADEN / REPAIR / PIVOT / CONCLUDE, plus one contingency route with an explicit trigger.

6 · Termination & Exceptional Pause

Exactly two final research outcomes are permitted; HUMAN_REVIEW_REQUIRED is temporary.

TARGET_REACHED

A Full Comparable Run meets the frozen Primary Metric target and every Hard Constraint passes.

TARGET_NOT_REACHED

Any registered hard cap among wall_clock_hours, gpu_hours, currency-tagged monetary_cost, and formal_experiment_count is exhausted before the target is reached.

HUMAN_REVIEW_REQUIRED

Allowed only for fundamental data or evaluation invalidity, an external blocker that remains after one Recovery Cycle, or an explicit user request to pause or change a frozen contract. Pure waiting time is excluded from the wall-clock budget, while actual resource use still counts.

Both outcomes must preserve

  • Final summary and budget usage
  • Best qualified model and full experiment lineage
  • Final metrics, remaining target gap, and reproducible artifacts
