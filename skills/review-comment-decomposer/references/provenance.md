# 来源与内容说明

## 自编返修规划

- `revision-planning.md` 根据作者确认的需求重新编写：结合原文理解意见、拆分可独立回答的问题、优先识别实验、并行安排回复构思、每条 comment 一条中文参考逻辑，以及生成可编译骨架。
- 原版本曾参考 https://github.com/moonlarry/codex-paper-skills 的 `f9d62749a4237134f4f9c5aafd063b4dcb29aad9` 快照，并包含原文摘录。当前版本已删除该摘录，入口不再引用它，也不再依赖其阶段命名、分类枚举或固定字数分配。
- 上述链接仅记录历史参考来源，不表示获有该仓库内容的再分发授权。当前规划说明按本项目需求重新组织表达，不是原摘录的逐句翻译或替换同义词。

## Paper2Rebuttal

- 来源：https://huggingface.co/spaces/Mqleet/RebuttalAgent
- 快照版本：`7da139704d8a25014ea060e7d09860f54ae9cf70`；本地下载记录及 Space 元数据声明 MIT。
- `issue_extractor.yaml` 保持本地快照原文不变，仅供读取其中拆分、合并与追溯方法。
- 实际执行的微调集中在入口：具体伦理等问题必须保留；共享方法主题不代表同一问题；原始评论保留完整，不强制使用来源中的 `[qN]` 输出标签。
- 未引入 writer/reviewer/strategy_generator 等其他提示词，避免继承预设期限、预测有利实验数值或虚构结果的指令。

- 本次使用已核对的本地副本；远端认证过期，未验证该副本与当前远端内容一致。此模板用于复用排版，不作为远端稿件备份。

- 修改内容：删去稿件内容、作者身份、投稿编号、真实实验与项目资源；去掉未使用和重复宏包；保留页边距、字体设置、评论框、回复标题和长表结构；加入虚构评论和明确占位符。
